# Story Mapping

Story mapping lays out everything a customer does on the site, from left to right, and then splits the work into releases.

| File | Contents |
|------|----------|
| `personas.md` | Who uses the store |
| `story-map.md` | The customer journey and stories under each step |
| `backlog.md` | Prioritized list of stories to build |
| `team-work-plan.md` | Who builds what, timeline, and how the team uses GitHub |
