# Architecture Decision Records (ADRs)

An ADR is a short note that records an important technical decision: what was decided, why, and what else was considered.

Name files with a number and a short title: `0002-payment-provider.md`.

## Template
```
# NNNN: Title
- Status: Proposed | Accepted | Replaced
- Date:

## Context
## Decision
## Consequences
```
