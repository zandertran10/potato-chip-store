# Data Model

Draft list of tables. Columns to be defined during design.

| Table | Purpose |
|-------|---------|
| `products` | Chip products (name, flavor, price, image) |
| `categories` | Groupings (e.g. classic, spicy, kettle) |
| `customers` | Customer profiles (linked to Supabase Auth) |
| `carts` / `cart_items` | Shopping cart contents |
| `orders` / `order_items` | Placed orders |
